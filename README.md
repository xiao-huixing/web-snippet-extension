# 网页片段

一个本地运行的 Chrome Manifest V3 扩展，用于按站点保存并回填常用文本或 SQL 片段。

## 功能

- 选中文本或聚焦输入框后，右键“保存为片段”
- 按站点或当前页面路径匹配片段
- 页面右上角浮层支持回填、复制、删除和保存当前内容
- 浮层支持收起或完全隐藏；完全隐藏后可点击 Chrome 工具栏中的“网页片段”扩展图标重新打开
- 独立管理页支持新增、编辑、重命名、移动、搜索和删除
- JSON 导入导出
- 数据存储于 `chrome.storage.local`，不上传服务器

## 手动安装

1. 打开 `chrome://extensions/`
2. 开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本项目目录

## 使用边界

- 支持普通 `input`、`textarea`、CodeMirror 5；CodeMirror 6 尝试通过可编辑区域回填
- 不支持的编辑器会自动复制到剪贴板
- 不允许保存密码输入框
- Chrome 内部页面和 Chrome 应用商店页面无法注入扩展
- 页面级匹配使用 `origin + pathname`，忽略查询参数和锚点
